# <초록> Magazine

GitHub Pages용 완성 구조입니다.

- index.html — Home
- chorok.html — 초록 / 잡지 아카이브
- stories.html — 이야기
- issues/ — 각 호
- stories/ — 개별 이야기
- assets/images/ — 표지 이미지
- style.css — 전체 디자인
- script.js — 햄버거 메뉴
- logo.svg — 임시 로고

## 가장 중요한 것
ZIP 안의 `logo.svg`는 임시 로고입니다. 이미 만든 네 `logo.svg`가 있다면 기존 파일을 유지하거나 ZIP의 파일을 네 로고로 교체하세요.

현재 표지는 `vol01-cover.svg`, `vol02-cover.svg`라는 임시 표지입니다. 실제 표지 사진/JPG/PNG가 있다면 `assets/images/`에 넣고 HTML의 파일명만 바꾸면 됩니다.
